# Rift Bastion · Suno Music Prompts

Original tactical sci-fi soundtrack for **Rift Bastion** (room-scale WebXR MR tower defense for Meta Quest 3). The score pairs tight analog-pulse electronics, dry low brass, muted orchestral strings, and restrained industrial percussion — built to energize combat while leaving clean frequency and transient headroom for spatialized ElevenLabs turret fire, cryo-arcs, railgun cracks, and portal-breach alerts on Quest 3 speakers.

**Start with `Tactical Command Deck` and `Broodlord Siege`.** Heard back to back, they should sound like the opening briefing and final boss climax of the same defense mission. Then audition `First Contact` and `Perimeter Overload` on Quest 3 speakers alongside turret fire and Core alarm cues on `audition.html`.

---

## Using These Prompt Sheets

- Use Suno **Custom** mode. Leave Lyrics empty on every cue.
- Each cue provides copy-ready **Style**, **Exclude styles**, and **Settings** blocks listed in exact Suno v6 Custom-panel order (`Instrumental` first, then `Vocal Gender`, `Duration`, `Max Mode`, `Weirdness`, `Style Influence`, `Variety`, `Personalize`, and `Model` last as a record).
- **Shared Musical Motif:** Every cue centers on **D minor** with a four-note tactical signature: **D3 → A3 → Bb3 → F3** (steady heroic leap, tense semitone rise, grounded fall). Keep takes where that pulse and harmonic identity are immediately recognizable without overpowering midrange SFX.
- **Mix Headroom Rule:** Keep `2 kHz–6 kHz` uncluttered (no shrill lead synths, cymbals, or siren-like sweeps) so autocannon transients, cryo-arc crackles, and portal warnings stay unmistakably legible in mixed reality.
- **One-Shot Stingers (`Sector Secured`, `Bastion Lost`):** Generate at `0:30`–`1:00` (or the shortest clean control option), then extract the clean opening phrase and natural reverb decay from the downloaded WAV during P4 mastering.

## Owner Handoff & Mastering Contract (Phase 4)

Per `~/.claude/guides/suno.md`:

1. **Generate & download WAVs:** Generate on the web interface (paid Suno account) and export full-song **WAV** files for the chosen takes.
2. **Handoff metadata to record per track** in `assets-source/audio/music/provenance.json`:
   - Cue role, Suno song ID/URL, generation date, actual selected model (`v6` or observed), account plan **at generation**, any prompt/setting edits, original filename, byte size, SHA-256, decoded duration, sample rate, channels.
3. **Immutable source preservation:** Archive raw WAVs untouched under `assets-source/audio/music/raw/` (outside `public/`). Never overwrite or normalize originals.
4. **Runtime mastering & loop preparation:**
   - Target loudness: **`-16 LUFS ±1`**, true peak **`≤ -1.0 dBTP`**, `48 kHz` stereo, **`≤ 2 MiB`** per runtime file.
   - Crossfade loop wrap must retain the post-intro body and rejoin the exact post-crossfade sample (never jump back through the consumed intro).
   - Export **Opus (`.ogg`)** with output-scoped FFmpeg `+bitexact` + fixed stream serial, plus **MP3 fallback (`.mp3`)** keeping FFmpeg's normal `Lavc` gapless header (do **not** strip `Lavc` with `+bitexact` on MP3).
   - Verify post-encode loudness, true peak, `0.5L + 0.5R` mono compatibility, zero interior quiet/zero gaps, and seamless loop wrap via `$validate-generated-assets` and on `audition.html` + Quest 3 speakers before runtime promotion.
